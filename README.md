# Compound Interest Calculator

## Explanation

This program calculates compound interest based on the principal amount, rate, time, and compounding frequency.

## Problem Statement

Write a Python program to calculate compound interest and the final amount.

## Formula

```text
A = P(1 + R / 100N)^(NT)
```

```text
Compound Interest = A - P
```

## Features

* Accepts principal amount
* Accepts interest rate
* Accepts time
* Accepts compounding frequency
* Calculates compound interest
* Calculates final amount

## How It Works

The program applies the compound-interest formula using the supplied values.

## Technologies Used

* Python 3

## Data Structure Used

* Floating-point variables

## Methods Used

* `input()`
* `float()`
* `int()`

## Program Flow

1. Read principal
2. Read rate
3. Read time
4. Read compounding frequency
5. Calculate final amount
6. Calculate compound interest
7. Display results

## Sample Input

```text
Principal: 10000
Rate: 5
Time: 2
Compounds per year: 1
```

## Sample Output

```text
Compound Interest: 1025.0
Total Amount: 11025.0
```
